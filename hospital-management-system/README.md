# Hospital Management System

## Overview

Hospital Management System is a menu-driven Core Java application that manages patients, doctors, and appointments. The project demonstrates OOP concepts, Collections Framework, Aggregation, CRUD operations, and reporting using Stream API.

## Features

### Patient Management

* Add Patient
* Display Patients

### Doctor Management

* Add Doctor
* Display Doctors

### Appointment Management

* Book Appointment
* View Appointments

### Reports

* Total Patients
* Total Doctors
* Total Appointments
* Doctor-wise Appointment Report

## Technologies Used

* Java
* OOP
* Collections Framework
* Stream API
* Aggregation
* Menu-Driven Programming

## Concepts Covered

### Aggregation

Appointment has a Patient and a Doctor.

### Collections

ArrayList is used to store patients, doctors, and appointments.

### Stream API

Doctor-wise appointment reports are generated using Collectors.groupingBy().
